# Sơ đồ công nghệ ONLINE — Pháp Điển AI

- Mở `So_do_cong_nghe_ONLINE.html`: phóng to/thu nhỏ, nhấp node xem lời thoại. Hoạt động offline, không gọi backend hay AI.
- `So_do_cong_nghe_ONLINE.svg`: hình vector rõ nét để đưa vào slide hoặc xuất ảnh.
- `So_do_cong_nghe_ONLINE.png`: toàn bộ sơ đồ (nếu có trong gói đã render).
- `Phan_1_...png` đến `Phan_4_...png`: hình từng phần để trình bày dễ đọc.
- `Loi_thoai_so_do_ONLINE.docx` và `Loi_thoai_30_buoc.md`: lời thoại 30 node, công nghệ, cách xử lý, output; mô tả đầy đủ các nhánh.
- `diagram_nodes.json`: nội dung nguồn dùng chung cho node và lời thoại.

Đối chiếu code local ngày 23/10/2026; không khẳng định phiên bản Kaggle đang chạy giống local. Màu là trách nhiệm chức năng, không là một dịch vụ/LLM riêng. Các node đánh số theo nhóm công việc để demo, không phải ID log runtime hay cam kết câu nào cũng chạy đủ 30 bước.
